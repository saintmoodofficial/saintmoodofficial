## ⚡ Чем занимаюсь

- 🗡️ Делаю **SAINT CLIENT** — клиент для Minecraft **1.21** на Fabric: боевые модули, визуал, HUD, кастомный интерфейс
- 🚀 Пишу к нему **лаунчер** на Rust (Tauri 2 + React) — установка и обновление в один клик
- 🎨 Рисую весь интерфейс сам: собственные шрифты, векторные иконки, пружинная анимация
- 🧩 Иногда ухожу в сторону: веб на TypeScript, автоматизация на Python

## 🔥 SAINT CLIENT

> Утилитный клиент, собранный вокруг одной мысли: **интерфейс не должен тормозить**.

<table>
<tr>
<td width="50%" valign="top">

**Что внутри**
- 30+ модулей: бой, движение, визуал, мир
- Собственный GUI в три колонки
- Кастомный HUD с редактором раскладки
- Профили конфигов
- Кинематографичное меню

</td>
<td width="50%" valign="top">

**Как сделано**
- Java 21 · Fabric Loader 0.16
- Ноль аллокаций в кадре рендера
- Фигуры через GPU-маски, а не по пикселям
- Пружинная физика анимаций
- Шрифты Inter · Montserrat · Z003

</td>
</tr>
</table>
